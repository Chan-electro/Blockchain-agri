# Quickstart

The canonical quickstart lives in the [README](./README.md#60-second-quickstart).

Short version:

```bash
npm install
npm --prefix smart-contract install
npm --prefix backend install

npm run dev       # starts chain + deploy + backend + frontend
npm run seed      # in a second terminal — creates demo users and batches
```

Open <http://localhost:5173> and sign in as any demo user (password
`demo12345`): `farmer@demo.agri`, `processor@demo.agri`, `logistics@demo.agri`,
`retailer@demo.agri`, `admin@demo.agri`.
